# Текст → визуал, продающие приёмы и цель сайта
Статус: предложено
Дата: 2026-10-13
Зачем: на главной слишком много текста; нужны примеры, как это решают другие, и зафиксированная цель сайта.
Что сделать: принять цель (ниже) и правило «блок = заголовок + одна строка + один визуал». После твоего «да» переделаю блоки по выбранным вариантам из соседних предложений.
Цена: сам файл ничего не ломает; переделка блоков 0,5–1 день каждый.

## Цель сайта (для фиксации)
Сейчас: **визитка** — кто Руслан, чем занят, как написать. Следующий этап: **визитка + продающий** — один понятный вход (интервью для эксперта) и один CTA «написать». Продающая часть добавляется, когда будут реальные доказательства (цитаты, кейсы, цифры). Пока их нет, блоков с ними нет.

## Правило для текста
Блок = заголовок + одна строка + один визуальный элемент (иконка, чип, схема). Список 3–4 пункта по 5–8 слов вместо абзаца. На мобильном bento становится вертикальным стеком.

## Примеры сайтов (разбор сделал вспомогательный агент по описаниям страниц; открывать руками, вес и анимации не мерили)
- [linear.app](https://linear.app/) — макеты вместо описаний, нумерованные панели «Fig 0.1». Ложится на нашу засечку.
- [framer.com/design](https://www.framer.com/design/) — bento из плиток «визуал + одна строка».
- [rauno.me](https://rauno.me/) — манифест из коротких строк, копирование email по клику.
- [niniaazzopardi.com](https://niniaazzopardi.com/) — 4 нумерованные карточки услуг; антипример: карточки по 25–70 слов.
- [kevin-indig.com](https://www.kevin-indig.com/) — один CTA в шапке и hero, блоки «заголовок + строка + кнопка».
- [daradenney.com](https://www.daradenney.com/) — «чего ожидать» тремя иконками.
- Подборка bento: [wannathis.one](https://wannathis.one/blog/best-bento-grid-examples).
- Структура продающего лендинга: [involve.me](https://www.involve.me/blog/landing-page-structure): одно обещание, один CTA, суть без скролла, доказательства рядом с CTA, короткие абзацы.

Оговорка: сайты консультантов в основном текстовые, приёмы взяты у продуктовых сайтов. Логотипы и выдуманные цифры не берём.
