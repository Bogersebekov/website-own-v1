# Предложения

Сюда агенты кладут идеи, которых Руслан не просил. Один файл — одно предложение:
`YYYY-MM-DD-slug.md`. В шапке статус: `предложено` → Руслан меняет на `принято` или `отклонено`.
Принятое делаем и переносим в ТЗ. Отклонённое не трогаем и не предлагаем второй раз.

Формат:

```
# Название
Статус: предложено
Дата: YYYY-MM-DD
Зачем: одна строка
Что сделать: 2–5 строк
Цена: сколько времени, что ломает
```
