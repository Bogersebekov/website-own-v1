# Замена блоку «Две двери»
Статус: предложено
Дата: 2026-10-13
Зачем: «две двери» — длинные абзацы и списки; название тебе не нравится. Нужно то же содержание, но в форме.
Что сделать: выбрать вариант. Тексты остаются в `site.ru.ts`, но короче: по одной строке и 3–4 чипа на сторону.
Цена: 0,5–1 день. Все варианты статичные (CSS/SVG), без тяжёлых библиотек.

Варианты (ответь «да / нет» на каждый, можно «да» на несколько — они сочетаются):

1. **Переключатель «Я эксперт / Я специалист»** — два больших ярлыка, под ними одна карточка меняется (чипы + одна кнопка). Мало места, ноль скролла. Рекомендую.
2. **Две крупные плашки-карты со срезом** — иконка, 3 слова, стрелка. Подробности по клику (раскрывается).
3. **Дорожка шагов** для эксперта: Интервью → Нарезки → Упаковка → Сайт → Воронка, как схема из точек. Для специалиста — вторая дорожка: Вход → Наработки → Команда.
4. **Тест «Кто ты?»** — один вопрос, два ответа-кнопки, ведёт в нужный блок. Лёгкий скрипт на 20 строк.
5. **Таблица «Что получаешь»** — две колонки, строки с галочками вместо абзацев.
6. **Названия вместо «две двери»**: «Выбери путь», «С чего начнём», «Кто ты», «Как работаем», «Два входа».
7. **«Чем мы не являемся»** превратить в ряд перечёркнутых чипов (Не фрилансеры · Не нейрослоп · Не чек-листы) вместо списка.

Моя сборка: 1 + 7, название «С чего начнём».
