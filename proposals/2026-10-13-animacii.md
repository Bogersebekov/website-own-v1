## Что такое «рауно»
Скорее всего rauno.me/craft: сайт Рауно Фрейберга с микро-взаимодействиями. Это не библиотека и не набор файлов, взять оттуда можно только идею и приём (код и ассеты автора не копируем). Уже стоит в `docs/referensy-animacij.md`. Если ты имел в виду Rive, ответ ниже тоже есть.

## Можно ли без лагов и тяжести
Да, если делать на CSS (браузер рисует на видеокарте) и анимировать только transform, opacity, clip-path, filter. Вес 0 КБ.

| Вариант | Вес (порядок, проверим перед выбором) | Когда нужен |
|---|---|---|
| CSS + немного JS (сейчас) | 0 КБ | почти всё из демо |
| Motion (motion.dev) | ≈3–20 КБ | пружины, сложные цепочки |
| GSAP + ScrollTrigger | ≈25–40 КБ | сложная прокрутка со сценами |
| Lottie | ≈60 КБ + файл на анимацию | готовые анимации из After Effects |
| Rive | ≈150 КБ + WebAssembly + файл | интерактивные персонажи и значки |

Рекомендация: остаёмся на CSS. Rive и Lottie подключаем только если появится конкретный ассет, который иначе не сделать.
