# Стек сайта: сравнение и выбор

Дата: 2026-10-13. Решение по умолчанию принято агентом, чтобы не стоять. Руслан может переиграть.

## Что нужно от стека

- Сайт-визитка сегодня, блог и новые страницы потом, английский потом.
- Мобильная и десктопная вёрстка, базовые анимации, фирменный стиль (свои шрифты, токены).
- Деплой на свой домен, без сервера и без ежемесячных платежей.
- Агенты должны легко добавлять страницы и записи без риска сломать всё.

## Три варианта

| | A. Astro (выбран) | B. Next.js + Vercel | C. Чистый HTML/CSS/JS |
|---|---|---|---|
| Что это | Статический генератор, HTML без JS по умолчанию, компоненты, коллекции контента | React-фреймворк с сервером | Файлы руками |
| Скорость первой версии | 1 день | 1–2 дня | полдня |
| Блог и новые страницы | встроено: markdown-коллекции, маршруты файлами | есть, но тяжелее | каждую страницу копировать руками |
| Языки | встроенная поддержка i18n-маршрутов | есть через библиотеки | руками |
| Вес страницы | минимальный, JS только где нужен | React-рантайм на каждой странице | минимальный |
| Хостинг | GitHub Pages, Cloudflare Pages, любой статик — бесплатно | Vercel (бесплатный тариф с лимитами) | любой статик |
| Риск для агентов | низкий: шаблон, тексты в одном файле, сборка ловит ошибки | средний: много способов сделать по-разному | высокий: дубли, расхождения стиля |
| Когда не хватит | если нужны личный кабинет, формы с сервером, API | — | как только страниц больше трёх |

## Решение

**Astro + ванильный CSS на токенах Jetix + GitHub Actions → GitHub Pages.**
Почему: статический сайт покрывает всё, что нужно сейчас и на год вперёд (блог, языки, страницы),
весит мало, бесплатен в хостинге, и его структура сама дисциплинирует агентов. Next.js нужен, когда
появится серверная логика; тогда переезд с Astro простой, тексты и стили переносятся как есть.

Формы (запись на интервью) делаем позже через внешний сервис или Telegram-бота, сервер не нужен.

## Хостинг и домен

- Сборка и деплой: `.github/workflows/deploy.yml`, push в `main` → сайт обновлён за 1–2 минуты.
- Домен: **jetixagency.com** (слово Руслана 13.10). `public/CNAME` уже лежит, `site` в `astro.config.mjs` = домен, `base` = `/`.
- DNS у регистратора (делает Руслан): для `jetixagency.com` четыре A-записи 185.199.108.153, 185.199.109.153,
  185.199.110.153, 185.199.111.153; для `www` CNAME на `bogersebekov.github.io`. Старые A-записи на VPS
  с корня убрать, сервер видео перевести на поддомен (например `video.jetixagency.com` → IP VPS).
- В GitHub: Settings → Pages → Custom domain `jetixagency.com`, после проверки DNS включить Enforce HTTPS.
  Инструкция: https://docs.astro.build/en/guides/deploy/github/
- ⚠️ GitHub Pages на приватном репозитории требует GitHub Pro. Если тариф бесплатный — репозиторий
  делаем публичным (код сайта и так виден всем) или переезжаем на Cloudflare Pages (тоже бесплатно).
