# ТЗ на сайт, версия 1

Дата: 2026-10-13. Собрано из запроса Руслана от 12.10 («Пожелания к сайту», «Структуры сайта по
образцу Nate Herk», «План страницы системы») и голоса 13.10. Слово Руслана — в кавычках. Остальное —
формулировки агента, ждут его правок.

## 1. Зачем сайт

Человек из аутрича открывает ссылку и за минуту понимает: кто Руслан, что делает сейчас, что строит
дальше и что предлагает ему. «Сайт должен вызывать чувство, что вот я профессионал». Сайт живой:
сюда можно заходить каждый день и видеть, что происходит.

## 2. Структура (образец nateherk.com, структура 1 «личный хаб»)

Главная, одна прокрутка:

| № | Блок | Что внутри | Статус v0.1 |
|---|---|---|---|
| 00 | Герой | Метка `// РУСЛАН РОМАНОВИЧ · BERLIN`, заголовок, одна фраза о том, что делаю сейчас, две кнопки, фото | есть, фото — заглушка |
| 00a | Регалии одной строкой | 12+ клиентов · 200+ касдевов · 60+ воронок · 30+ систем (его цифры 12.10) | есть |
| 01 | Чем занят сейчас | 4 карточки со статусами вместо цифр: Jetix Agency, фирма, интервью, Live OS | есть |
| 02 | Работать со мной | Две двери: эксперту (упаковка) и специалисту (вход в фирму); «чем мы не являемся» | есть |
| 03 | Кто я | «Тренер, который тренируется сам», 3 абзаца, 5 ценностей | есть |
| 04 | Строю публично | Журнал по датам из markdown-записей, страница «все записи» | есть, 3 записи |
| 05 | Связь | Одно действие: Telegram | ждёт ссылку |

Страницы следующими версиями:
- `/journal/` — журнал целиком (есть) → растёт в блог.
- `/live-os/` — страница системы управления жизнью, шаблон в Notion (план в Notion «План страницы системы»).
- `/en/` — английская версия (не раньше, чем русская устоится).
- Лента активности «как точки на GitHub» — после решения, откуда данные (коммиты, Notion, вручную).

## 3. Дизайн

Источник: скилл `jetix-design`, карточка К-4 (утверждена 11.10).
- Тёмная тема основная. Холст `#13111C`, оранжевая сетка с перспективой 18 %, тёплые зоны, свечение.
- Шрифты: HS Luna Obscura (заголовки, КАПС), Iosevka 200/400/800 (всё остальное). Хостим сами.
- Форма: срез углов, стекло-плашки с кромкой 1 px и оранжевой чертой 2 px сверху. Скруглений нет.
- Цвет: оранжевый `#FF5500` только знак, засечки, метки. Кнопки синие `#1D4596`. Статусы: зелёный
  «в работе», синий «собираю», жёлтый «скоро».
- Плотность: 1 заголовок + 1 зона данных + 1 действие на экран, половина площади — пустой фон.
- Голос: на «ты», прямо, без воды. Цифры только реальные.

## 4. Анимации

- Появление блоков при прокрутке: 280 мс, сдвиг 14 px, ступенчатая задержка карточек.
- Наведение на карточку: подъём 3 px, 200 мс. Кнопка: подъём 2 px, стрелка у текстовой кнопки.
- Фон: медленный дрейф сетки, петля 40 с (фоновые петли разрешены).
- `prefers-reduced-motion`: всё выключено.
- Следующие: счётчики регалий, бегущая строка статусов, видео в герое — только после слова Руслана
  (см. `proposals/`).

## 5. Техника

- Astro 7, статическая сборка, ванильный CSS на токенах, один `<script>` на появление блоков.
- Тексты в `src/data/site.ru.ts`, журнал в `src/content/journal/*.md`.
- Мобильная вёрстка от 360 px, брейкпоинты 640 / 768 / 900 / 1200.
- SEO: title, description, canonical, OG, sitemap. Favicon временный (срезанный квадрат).
- Деплой: GitHub Actions → GitHub Pages, push в `main`.
- Доступность: контраст по токенам, фокус-кольца, кнопки ≥ 40 px, семантика секций.

## 6. Чего на сайте нет (пока он не скажет)

политики, религии, войны, национальных тем · видео (позже).
