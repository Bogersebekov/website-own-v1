# Выбрано: «Срезанные углы» · 17.10.2026

Владелец подтвердил этот вариант для всех страниц сайта. Это актуальное решение после сравнения трёх доработок типографики.

## Тексты

- Сумма: **35 000+ долларов**.
- Подпись: **Выручка, сгенерированная за 3 месяца**.
- Выполнено: **Протестировано 8 воронок продаж** — без «более».
- Остальные факты сохранены: четыре лендинга, 13 кастдевов, июнь–октябрь 2025 и отдельная строка «Полное продюсирование».

Выбрана грамматически согласованная подпись к сумме. Другие рассмотренные варианты: «Выручка за 3 месяца», «За 3 месяца сгенерировано выручки». Не применять без новой правки.

## Дизайн

На первом экране оранжевым выделены «консалтинговую фирму», «Строю» и «публично» светлые. Основные строки имеют единый кегль и интерлиньяж; вводное «Строю» меньше. Длинное слово помещается целиком на 320–1440 px, переносы между основными строками заданы явно.

Главная и четыре внутренние страницы используют фон с дымкой, тёплые контуры, срезанные углы плашек, одинаковые CTA без стрелок. Внутренние страницы получили общее меню разделов с текущим пунктом, акцентный первый экран и единое оформление заголовков, списков и таблиц.

На основных маршрутах нет панели сравнения вариантов. Навигация ведёт между /, /firm/, /agency/, /interviews/ и /life-os/. Маршруты /refine/ сохранены для истории сравнения.

## Проверка и просмотр

`npm run build` успешен. Проверены все пять страниц на 1440, 768, 390 и 320 px: отсутствие горизонтального переполнения, один H1, правильные акценты, новые факты и единый выбранный стиль. Проверены переходы между страницами и просмотр скриншотов.

Экспорт пяти страниц: `python scripts/export-preview.py /workspace/artifacts/jetix-facet/offline selected` после сборки. ZIP: /workspace/artifacts/jetix-facet/jetix-site.zip. Распаковать полностью, открыть index.html. Прямой file://-режим в браузере среды блокируется политикой, поэтому копия проверяется через локальный HTTP; относительные ссылки не требуют сервера при обычном открытии файлов.
