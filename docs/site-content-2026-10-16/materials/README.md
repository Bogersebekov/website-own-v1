## Как передать

- Можно прикреплять фото, скриншоты и видео прямо в чат, отдельными сообщениями или одним ZIP-архивом с папками promotion/, websites/, course-workshop/.
- Рядом указать назначение и короткую фактическую подпись: что показано, какая работа выполнена. Для сайтов полезна ссылка и пояснение личного вклада.
- Желательны оригинальные PNG/JPG/WebP для изображений и MP4 для видео. Другие форматы сначала проверить по фактическому файлу; перекодировать заранее необязательно.
- Если большой файл не прикрепляется — передать ссылку на скачивание с предоставленным доступом. Успешную загрузку и доступ проверить до регистрации материала как полученного.
- После получения фиксировать фактический файл, источник, назначение, подпись и статус использования в таблице ниже. Исходники сохранять; под сайт делать отдельные оптимизированные копии.

## Как использовать видео

Можно встроить короткие ролики в карточки продвижения: обложка, запуск по нажатию, стандартные элементы управления, просмотр на телефоне. Реализация — следующий технический этап. Не нужно сначала делать отдельный видеопроект, чтобы передать материалы.

После получения проверить размер, длительность, ориентацию, кодеки и звук. Затем выбрать размещение: небольшие подготовленные файлы могут храниться рядом с сайтом; тяжёлые — на подходящем хостинге. Не загружать большие оригиналы в Git вслепую. Не включать одновременный автозапуск со звуком; не загружать все полные ролики при открытии главной. Если речь важна для понимания, при подготовке предусмотреть субтитры.
