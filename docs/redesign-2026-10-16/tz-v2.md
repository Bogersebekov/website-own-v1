# ТЗ v2: редизайн «Кинозал»

Версия: черновик 2026-10-16. Заменяет визуальную часть `docs/tz.md`; тексты не меняются.

## 1. Стиль
- Токены: `src/styles/jx-v2.css` и `or-acc.css`. Оранжевый только знак и засечка, кнопки синие, срез угла 16 px.
- Шрифты: из `src/assets/fonts/`. Чего нет в скилле jetix-design, согласуем с Русланом.
- Только тёмная тема. Минимальный контраст текста 4.5:1.

## 2. Каркас (на каждой странице)
Шапка: логотип, ссылки на разделы, кнопка в Telegram. Подвал: контакты. Фон: сетка, которая проявляется один раз при загрузке.

## 3. Главная (8 блоков из `home-copy.md`)
1. **Герой «Кинозал»**: фото Руслана в сцене с генератора на всю высоту, заголовок слева, кнопка. Свет на фото, мягкое свечение, сканирующая линия раз в цикл.
2. **Что строю** и **Мои проекты**: стеклянные карточки.
3. **Прошлый опыт** (K-001): HUD-рамка, цифра крупно, без выдумок.
4. **С чем могу помочь**: четыре плашки со срезом с значками.
5. **Интервью**: постер-карточка с обложкой.
Остальные страницы (/firm, /agency, /interviews, /life-os): каркас и карточки те же, блоки по их документам.

## 4. Карточки
Четыре формы (превью: https://claude.ai/artifact/VMciUxZP977qLrGsfKc3EE): плашка (услуги), HUD (цифры, опыт), стекло (смысловые блоки), постер (проекты, интервью).

## 5. Анимации
Появление блока ≤300 мс, свечение при наведении, сканирование героя, живой фон по выбору (видео или canvas). `prefers-reduced-motion`: всё выключается, остаётся статика.

## 6. Картинки с генератора
Нужны: обложка героя (сцена), обложки блоков (проекты, интервью), единый набор значков. Стиль: киберпанк-лаборатория, тёмный, синий свет, один оранжевый акцент. Без людей и логотипов, которых нет в реальности. Формат: webp, герой 2400 px, обложки 1200 px.

## 7. Приёмка
`npm run build` без ошибок; мобильный и десктоп; контраст; клавиатура; reduced-motion; вес первой страницы разумный; все кнопки ведут по реальным ссылкам, нерабочие не публикуются.

## 8. Открытые вопросы Руслану
Ссылки Telegram, YouTube, Instagram; портрет в высоком качестве; формат фона героя (видео или картинка); потолок анимации.
