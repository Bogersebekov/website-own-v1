# Стек: оставаться на Astro?

Решение: **остаёмся на Astro** (подтвердил Руслан 2026-10-16: «Астру берём»).

| Что нужно для «Кинозала» | Astro | Next.js |
|---|---|---|
| Статичные страницы, быстрый старт | да, HTML без JS по умолчанию | да, но тяжелее |
| Анимации появления и свечения | CSS и небольшой скрипт | то же |
| Живой фон (canvas, шейдер) | остров-компонент, грузится только в герое | то же |
| Сцены при скролле (GSAP) | подключается там, где нужно | то же |
| Блог и языки | коллекции и i18n встроены | есть, сложнее |
| Хостинг | GitHub Pages уже работает | Vercel |
| Риск для агентов | низкий | выше |

Что добавляем при нужде: GSAP с ScrollTrigger или чистый CSS `animation-timeline` для скролла; фон героя: готовое видео/webp с генератора или лёгкий canvas. Тяжёлый WebGL только по отдельному слову Руслана.
Когда пересмотреть: если появятся личный кабинет или серверная логика.
