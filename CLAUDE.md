# website-own-v1 — правила для агентов

Сайт Руслана Романовича и Jetix. Владелец — Руслан, Берлин. Ты — его AI-оператор.
Язык содержания — русский. Код, конфиги, коммиты — по конвенции ниже.

## Главное

1. **Стиль только из скилла `jetix-design`** (`Bogersebekov/skills-for-agents`, `skills/jetix-design/SKILL.md`).
   Токены лежат здесь: `src/styles/jx-v2.css`, `src/styles/or-acc.css`, шрифты в `src/assets/fonts/`.
   Срез углов, стекло-плашки, оранжевый только как знак и засечка, синие кнопки, анимации ≤300 мс,
   `prefers-reduced-motion` всегда. Чего нет в скилле — вопрос к Руслану, не импровизация.
2. **Цифры и факты только реальные.** Нет данных — не пишем. Цены, проценты, выдуманные кейсы,
   логотипы и люди на сайте запрещены. Политика, религия, война, национальные темы — нет.
3. **Тексты главной — в `src/data/site.ru.ts`**, не в компонентах. Так потом добавится `site.en.ts`.
4. **Прогресс пишем в Notion.** После каждой сделанной задачи (не каждого коммита) добавь строку в журнал
   страницы «🛠 Сайт: план, журнал, обратная связь» в Notion (ссылка в `docs/notion.md`): дата, что сделано,
   ссылка на коммит или PR. Вопросы к Руслану — в раздел «Обратная связь и вопросы» той же страницы.
   Копия журнала живёт в `docs/zhurnal.md` — обновляй обе.
5. **Предложения — в папку `proposals/`.** Любая идея, которую Руслан не просил (новый блок, анимация,
   страница, интеграция) — отдельный файл `proposals/YYYY-MM-DD-slug.md` со статусом `предложено`.
   Руслан ставит `принято` или `отклонено`. Принятое делаем, остальное не трогаем. В код без его слова
   предложения не попадают.
6. **Не ломай деплой.** `npm run build` проходит без ошибок перед каждым коммитом в `main`.
   Push в `main` = деплой на сайт.

## Устройство

```
src/data/site.ru.ts        тексты главной (один файл на язык)
src/content/journal/       записи журнала «строю публично», YYYY-MM-DD-slug.md
src/components/            блоки главной: Hero, Facts, Now, Doors, Story, Journal, Contact
src/layouts/Base.astro     каркас страницы: шапка, фон, подвал, анимация появления
src/pages/                 маршруты: index, journal/
src/styles/                токены Jetix + global.css (слой сайта)
src/assets/                шрифты, фон-сетка
public/                    favicon, CNAME (когда домен подключён)
docs/                      ТЗ, стек, журнал, решения
proposals/                 предложения агентов, ждут слова Руслана
```

## Как добавлять

- **Новая страница:** `src/pages/<slug>.astro`, обёртка `<Base title=... description=...>`, блоки из `src/components/`.
  Ссылки внутри сайта — через `import.meta.env.BASE_URL` (см. компоненты), пока сайт живёт с `base`.
- **Запись журнала:** md-файл в `src/content/journal/` с полями `title`, `date`, `tags`. Это и будущий блог.
- **Новый язык:** `src/data/site.en.ts`, папка `src/pages/en/`, записи с `lang: en`. Пока только русский.
- **Блог позже:** та же коллекция `journal`, при нужде вторая коллекция `blog` в `src/content.config.ts`.

## Конвенции

```
файлы      kebab-case
даты       YYYY-MM-DD
коммиты    [область] что сделано     (например: [site] герой с фото, [docs] ТЗ v1)
ветки      main = прод; фичи в ветках, PR в main
```

## Безопасность

- Ключи, пароли, токены — не в репозиторий.
- Ничего не отправляй наружу (посты, письма) без прямого слова Руслана.
- Не удаляй файлы без его подтверждения.
