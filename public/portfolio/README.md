# Портфолио — куда класть файлы

Блок «Примеры работ» есть на главной (`/`) и на странице агентства (`/agency`).
Пока файла нет, на его месте серая рамка «Пример появится скоро». Положил файл → пересобрал сайт → он появился.

| Папка | Что | Имена файлов |
|---|---|---|
| `course/` | скриншоты курса по продвижению (3 места) | `course-1.webp`, `course-2.webp`, `course-3.webp` |
| `sites/` | примеры разработанных сайтов (3 места) | `site-1.webp`, `site-2.webp`, `site-3.webp` |
| `video/` | контент и монтаж (3 места) | `video-1.mp4` + обложка `video-1.webp` (или только обложка `video-1.webp`) |

- Форматы картинок: `.webp` (лучше), `.jpg`, `.png`, `.avif`. Видео: `.mp4` или `.webm`.
- Пропорция рамки 16:10, ширина ~1600 px. Другая пропорция обрежется по центру.
- Видео держи короткими и лёгкими (до ~15 МБ): файл лежит прямо в репозитории. Длинное видео лучше
  залить на YouTube / сервер Cap и попросить агента вставить ссылку.
- Подпись под примером и название групп — в `src/data/site.ru.ts`, объект `portfolio` (поле `caption`).
- Меньше трёх примеров в группе? Удали лишний слот в `portfolio.groups[…].slots`.
- Только реальные работы и с разрешения клиента. Имя эксперта K-001 не раскрываем.
